Why Is My Site Coming from California?

Customer question

My visitor is in London, but my website's IP address appears to be in California. Why?

Customer-facing response

Hello,

I understand why this looks concerning. Cloudflare uses a network technology called Anycast, which allows the same IP address to be announced from multiple locations. Internet routing directs a visitor's traffic to an appropriate available Cloudflare data centre.

An IP geolocation database may label an IP address as being in California even when your visitor's traffic is being handled by a Cloudflare data centre much closer to London. The location shown by an IP lookup does not necessarily identify the data centre serving your request.

We can investigate using the CF-Ray response header, which includes a code identifying the Cloudflare data centre that handled the request. We can also compare test results and review available traffic analytics.

If you share the affected URL and the response headers, we can help determine which Cloudflare location handled the request and investigate any performance concerns.

Kind regards,
Cloudflare Support

Troubleshooting rationale

Anycast allows the same IP address to be advertised from multiple locations. IP geolocation databases can be inaccurate or outdated, so an IP address labelled as Californian does not prove that the request was served from California.

Tools used and why

  • curl: Inspect HTTP response headers.
  • CF-Ray: Identify the Cloudflare data centre code in the response.
  • Cloudflare Analytics: Review available traffic and performance information.
