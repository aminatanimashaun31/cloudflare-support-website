Redirect Based on User Agent

Customer question

I want to redirect visitors using Internet Explorer 8, identified by a user agent containing MSIE 8.0. Page Rules do not support this condition. Is there another way?

Customer-facing response

Hello,

Yes. A Cloudflare Worker can inspect the incoming request's User-Agent header and return an HTTP redirect when it matches your condition.

For example, the Worker can check whether the header contains "MSIE 8.0". If it does, the Worker can return a 302 temporary redirect to the destination you choose. Otherwise, it can allow the request to continue.

To use this approach, deploy the Worker and configure a route that matches the relevant website URL. Test it with both matching and non-matching user agents before applying it to production traffic.

Please note that user-agent strings can be changed or spoofed by clients, so they should not be used as a security control. A temporary redirect is useful while testing; choose a permanent redirect only if that is genuinely the intended behaviour.

Kind regards,
Cloudflare Support

Troubleshooting rationale

A Worker can evaluate request headers and apply custom logic that may not be available in Page Rules. A route must match the request, and the Worker must be deployed. The user-agent value is not reliable proof of a browser's actual identity.

Tools used and why

  • Cloudflare Workers: Implement the conditional redirect.
  • Worker logs: Investigate requests and runtime behaviour.
  • curl: Test with different User-Agent headers and inspect redirect responses.
