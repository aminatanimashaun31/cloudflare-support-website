Are Your Nameservers Down?

Customer question:

I cannot access my website from different networks. Are your nameservers down?

Customer-facing response

Hello,

I'm sorry you're having trouble accessing your website. A website being unreachable does not necessarily mean that its nameservers are down. Let's investigate the DNS configuration and the website's origin server.

First, we should check whether the domain delegates to the expected authoritative nameservers and whether those servers return the correct DNS records. We should also check for DNSSEC errors, the Cloudflare status page, and whether the origin server is reachable.

Tools such as dig or nslookup can help verify DNS responses. We can also use curl to test the website's HTTP response.

Once we identify where the failure occurs, we can recommend the appropriate fix. Please share the domain name and any error messages so we can investigate further.

Kind regards,
Cloudflare Support

Troubleshooting rationale

We should not assume a nameserver outage based only on a browser error. The issue could be related to DNS delegation, DNSSEC, DNS records, the origin server, or network connectivity.

Tools used and why

  • dig / nslookup: Inspect DNS records and responses.
  • Cloudflare Status: Check for reported service incidents.
  • curl: Test HTTP connectivity and response headers.
