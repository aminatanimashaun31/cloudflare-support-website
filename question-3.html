Why Is My Worker Not Applied?

Customer question

I added a Worker in the Cloudflare dashboard. It works in the debugger, but it does not run when I visit my website. Is there anything I need to activate?

Customer-facing response

Hello,

I'm glad your Worker is working in the debugger. The next step is to check that it is deployed and configured to handle requests for your website.

First, confirm that the Worker has been deployed. Then check that its route matches the URL you are testing, including the hostname and path pattern. For example, a route such as example.com/* matches requests for paths on that hostname.

If the route uses a custom domain, verify that the domain configuration is correct. If you are using a route on a website hosted through Cloudflare, confirm that the relevant DNS record is proxied through Cloudflare.

Also check the Worker logs and test the exact URL that should trigger it. If the issue persists, please share the Worker route pattern, deployment status, and a sample URL so we can investigate further.

Kind regards,
Cloudflare Support

Troubleshooting rationale

The debugger tests Worker code, but it does not prove that production requests match the deployed Worker. A missing deployment, incorrect route, hostname or path mismatch, or DNS proxy configuration can prevent the Worker from handling the expected request.

Tools used and why

  • Cloudflare Dashboard: Verify deployment and route configuration.
  • Worker logs: Investigate requests and runtime errors.
  • curl: Test the actual URL and inspect the response.
